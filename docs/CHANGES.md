# Changes

- Added private, persisted per-file tool checkpoints for native `write_file` and `edit_file` when a `checkpointStore` is configured. Backups store full bounded original/result bytes and SHA-256 hashes outside the workspace; preview text is not a backup. Restore checks active session and exact current hash, supports created-file removal, and rejects symlink/path escapes. Pending records remain non-restorable.
- Registered native read-only `git_status`, `git_diff`, and `git_log` tools, including in readonly mode. Git inspection refuses repository fsmonitor hooks/external diff and other executable configuration, omits forbidden paths, redacts known values, bounds output, and reports omissions. Git observations are not tool checkpoints. No automatic git initialization or commits.
- Git diff now forces literal pathspec interpretation for tracked filenames, preventing a filename such as `:(glob)*` from expanding a permitted per-file diff to forbidden `.env` blobs. A real temporary-repository regression covers pathspec magic, leading dashes, newlines, and honest omissions.
- Executable file modes are preserved through native replacement and checkpoint restore. Completion verifies the actual resulting file hash; Unicode diff previews are byte-capped with an explicit truncation marker. Regression tests cover failed backup storage, false completion, external edits, symlinks, cancellation, reload, and full originals beyond previews.
- Integration: hosts integrate the exported checkpoint APIs directly; coordinator-local
  `.build/` contract notes are **not shipped** and are not required reading. Existing local registry without a configured store remains legacy/nonreversible; hosts must supply a private store for reversible edits. Hosts must hold a cross-process session exclusion lock for the entire restore; a single active-session query is insufficient.
