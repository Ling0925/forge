# Android 局域网客户端

Android 是远程工作台，不在手机运行 Forge 核心。扫码保存电脑上的 HTTP 工作台地址，然后通过 WebView 加载与 Web 版相同的 React 界面；普通操作使用 HTTP RPC，运行输出通过 WebSocket 推送。

## 从桌面连接

1. 构建当前桌面源码（`pnpm build`）并重新启动源码桌面应用（`pnpm desktop`）。不需要重新安装，也不要覆盖未知的本机启动器。
2. 打开 **设置 → 手机连接**，选择电脑的局域网 IPv4、端口和服务器上的默认工作区。
3. 点击 **开始公开**，显示地址和二维码后，在 Android App 中扫码，或手动输入地址。
4. 手机与桌面使用同一个正在运行的核心：同一会话中的输出、权限与待处理审批可以在两端查看和操作。另开普通浏览器访问该地址也可以。

局域网监听默认关闭，必须明确开启；开启后默认要求设备授权。二维码仅包含连接地址，不是授权凭证。当前 Android 地址扫码流程尚不会交换凭证，现有客户端需由宿主显式选择可信 LAN 兼容模式，或通过客户端实现核心配对接口；步骤和 HTTP 风险见 [LAN 设备授权](LAN_AUTHORIZATION.md)。浏览器授权 cookie 不会自动共享给 Android WebView。

桌面公开的服务允许访问桌面核心中的多个工作区，会话列表与桌面一致；选定的工作区是手机创建新会话时的默认值。这里的文件路径、Git、命令、模型调用、MCP 和子代理都在电脑上执行，不是手机本地。

- 手机断网、切后台、退出 App：任务继续由电脑核心持有。
- 重新进入：Web 桥接尝试恢复连接和当前输出；刷新后从“最近任务”重新打开相同会话即可查看，不会重新执行任务。连接过期时按提示刷新。
- 桌面多工作区公开时，暂不支持从文件变更卡片直接预览 HTML 文件（相对路径无法确定工作区）；会话内 HTML 代码块预览不受影响。独立 Web 固定工作区仍支持文件预览。
- **停止公开**：断开远程连接，不取消核心中正在运行的任务。
- **关闭桌面应用或重启核心**：会停止/取消其持有的任务。手机不能让已经退出的电脑核心继续运行。
- 审批由核心消费一次，手机处理后其他在线页面会移除相同审批；失败的 HTTP 操作不会自动重发。

## 从独立 Web 服务连接

不需要 Electron，也不依赖 Vite 热更新服务器：

```sh
pnpm build:web
pnpm serve:web --host 192.168.1.2 --port 5173 --workspace /absolute/path/to/project
```

替换为电脑实际的 IPv4 和项目路径。不传 `--host` 时仅监听 `127.0.0.1`，手机无法通过该回环地址访问；不接受 `0.0.0.0`。启动后浏览器打开打印的 URL，在 **设置 → 手机连接** 查看二维码。Android 扫码或手动输入同一个 URL。

独立 Web 服务保持固定工作区；`pnpm dev:web` 是多工作区开发入口。多个浏览器和手机接入同一个 Web 服务时共用该服务的运行状态。**单独启动的 Electron 与 Web 进程不是同一个核心**：要与桌面配合，请连接桌面内开启的局域网入口，不要另起 Web 进程来冒充桌面活动任务。CLI 仍是独立运行入口，不自动接管桌面/Web 活动任务。

Web 服务依旧尊重 `FORGE_HOME`。开发、自动验证请用临时目录，避免读取真实凭据或写入真实会话。界面文件由服务端提供，更新界面后刷新手机即可；更新后端需要先结束当前任务再重启服务。

## 构建 Android APK

工程、版本要求和构建步骤见 [`android/README.md`](../android/README.md)。需要 Android SDK、JDK 和对应 Gradle 环境；Java/ADB 本身不代表 APK 工具链齐备。构建产物不纳入 Git。

首版提供扫码、手输地址、最近地址、更换连接和系统图片选择。使用较新的 Android System WebView（共享界面构建目标为 Chromium 132）。尚不提供 Android 后台常驻 WebSocket、推送通知、离线核心或手机本地工作区。
