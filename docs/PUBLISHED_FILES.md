# 对话文件交付

模型先用现有工具创建用户需要的文件，再调用：

```json
{"path":"outputs/report.md","displayName":"分析报告.md","description":"本次分析结论"}
```

工具名为 `publish_file`。`path` 必须相对当前工作区，`displayName`、`description` 可省略。只有工具成功后才算发送，路径文本和 Markdown 链接不会创建附件。

## 体验

- Web / 桌面工作台：本轮回复下方显示附件卡片，不藏在默认收起的执行过程里。显示文件名、字节大小和描述；可预览或下载。
- PNG / JPEG / GIF / WebP：签名检查后显示缩略图并可放大。SVG 不内联渲染。
- UTF-8 文本、Markdown、代码、CSV 等：不超过 1 MiB 时纯文本预览，不执行内容。Web 上的 HTML 可复用隔离预览；桌面上回退为源码预览。
- PDF、Office、压缩包及其他格式：提供下载，不承诺内置预览。
- 桌面“下载”走原生保存对话框；浏览器默认下载仍被桌面安全规则禁止。Web 通过有界 RPC 获取字节并由浏览器下载。
- CLI 列表与保存：

```sh
forge files list <session-id> --json
forge files save <session-id> <file-id> --output ./报告.md
```

CLI 要求显式输出路径，不覆盖已有文件。

## 数据与安全边界

- 单文件 50 MiB（52,428,800 字节）；单个发布会话最多 128 个文件、原始字节总计 64 MiB。存储使用 base64，磁盘实际占用比原始字节大约多三分之一。
- 发布复制发送时的不可变快照，保存于 Forge 状态目录的 `published-files/` 中。之后修改、删除工作区原文件不会影响附件。再次发布创建新附件。
- 会话消息和事件只包含元数据，不包含附件字节；模型上下文不会被文件内容挤占。
- 获取附件需要会话中真实成功的 `publish_file` 引用；其他会话不能仅凭文件 ID 读取。Fork 保留边界内的引用，共用不可变快照；边界前不包含该文件的 Fork 无权读取。
- 工作区越界、符号链接、硬链接、敏感路径、受保护状态目录、已知密钥与常见私钥/令牌内容会被拒绝，`unrestricted` 也不绕过这些边界。此检查是防护，不是对任意二进制内容的完整 DLP 扫描。
- `readonly` / plan 模式不允许发布。
- 下载时验证存储私有权限、大小与 SHA-256；Web 沿用 Host / Origin / 页面连接 / 工作区访问控制，没有新增任意路径静态下载接口。

## 第一版限制

没有附件删除/垃圾回收界面、跨机器附件导入或大文件流式/断点下载。失败/中断的发布可能占用配额，采用先预留额度再保存的保守策略，避免崩溃产生无配额约束的文件。导出会话 JSON 不包含附件字节，迁移附件需另行处理。

本机 CLI 更新仍只需 `node scripts/build-core.mjs` 后重新打开 `forge`。分离部署后，UI 更新只重启 `forge-web.service`，对话继续由 `forge-core.service` 执行；Core 代码/附件上限更新仍需等任务结束后重启 Core。桌面源码已接入，但不会自动覆盖旧桌面发布包或改动启动器。
