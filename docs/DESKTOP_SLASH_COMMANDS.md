# 桌面 Slash 命令

在桌面聊天输入框输入 `/` 打开命令列表；继续输入可过滤。↑/↓ 选择，Tab 补全，Enter 执行，Esc 收起（保留草稿），也可以点击选项。中文输入法确认候选时不会执行命令。

| 命令 | 操作 |
| --- | --- |
| `/help` | 显示本地帮助 |
| `/new` | 打开新会话，不立即创建或请求模型 |
| `/model` | 打开现有模型选择器 |
| `/mode` | 打开 Build / Plan 选择器，作用于下一次运行 |
| `/permission` | 打开现有权限选择器，不自动提升权限；Plan 空闲时禁用 |
| `/settings` | 打开设置，未配置模型时也可用 |
| `/stop` | 请求停止当前会话的运行 |

这些命令由桌面端本地处理，不发送给模型。目前不支持命令参数，也不是 CLI 全量命令的映射；未知命令会提示并保留输入。以 `/` 开头的普通消息请使用 `//` 转义，例如 `//tmp/project` 会发送 `/tmp/project`。

本轮只需 `pnpm exec vite build` 更新 `dist/renderer`，不需要 CLI 编译、Electron 打包或重新安装。使用仓库构建产物的桌面窗口需重新加载；旧发布包不会自动更新。
